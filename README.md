# BigTechoTest — диагностика ПК и ноутбуков

Бесплатная программа полной диагностики компьютера от **Big Techno Club**: проверяет процессор, память, видеокарту, диски, блок питания, охлаждение, драйверы и Windows, находит неисправности и предупреждает о тех, что скоро появятся. В конце — понятный отчёт.

## ⬇ [Скачать BigTechoTest.exe](https://github.com/nigastyle/BigTechoTest-releases/releases/latest/download/BigTechoTest.exe)

1. Скачайте **BigTechoTest.exe** по ссылке выше и запустите (нужны права администратора).
2. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
3. Выберите режим (быстрая / полная проверка / по жалобе) и нажмите «Начать диагностику».

Windows 10 / 11, 64-бит. Нужные для тестов утилиты программа скачивает сама из официальных источников и сверяет контрольные суммы.

## Обновления

Программа обновляется сама при запуске — прямо отсюда, с GitHub. Обновление ставится только если манифест `version.json` подписан нашим ключом (RSA-3072), а контрольные суммы файлов совпали.

## Файлы в релизе

| Файл | Зачем |
|---|---|
| **BigTechoTest.exe** | программа — скачать и запустить |
| BigTechoTest.cmd | та же программа одним сценарием (для автообновления и запуска без exe) |
| BTT-Drivers.ps1 | модуль автоустановки драйверов |
| version.json, version.sig | манифест версии и его подпись — нужны только для автообновления |

Архивы «Source code» GitHub добавляет автоматически — они не нужны.
